# Assignment acceptance checklist

and observed on this machine; anything that could not be executed here is

## Application functionality

- [x] **Frontend connected to FastAPI** - the SPA reads every screen from the
      API; `scripts/verify.sh` passes through the frontend origin.
- [x] **PostgreSQL persistence works** - data survives `docker compose restart
      backend`; verified via `GET /api/stats`.
- [x] **Course listing works** - `GET /api/courses` returns a paginated
      envelope (17 seeded courses, 6 pages at the default page size).
- [x] **Course details work** - `GET /api/courses/{id}` returns description,
      aggregates, distribution and recent feedback.
- [x] **Review submission works** - `POST /api/courses/{id}/reviews` returns
      201 and the review appears immediately in the course aggregates.
- [x] **Same email cannot review the same course twice** - returns 409
      `DUPLICATE_REVIEW`; case and whitespace differences are also rejected.
- [x] **The duplicate rule survives a race** - a pytest test fires two
      simultaneous submissions and asserts exactly one row and one 409.
- [x] **Average rating works** - computed in SQL over visible reviews only.
- [x] **Review count works** - matches the number of visible reviews.
- [x] **Category filtering works** - case-insensitive.
- [x] **Rating filtering works** - `min_rating` filters on the computed average.
- [x] **Search works** - across title, mentor, category and description.
- [x] **Sorting works** - rating, review count, newest, title.
- [x] **Pagination works** - `page`, `page_size` (capped at 50), `pages`, `total`.
- [x] **Rating distribution works** - 5→1 buckets with counts and percentages.
- [x] **Admin can sign in** - `POST /api/admin/auth/login` returns a JWT.
- [x] **Admin can create courses** - 201, slug generated server-side.
- [x] **Admin can edit courses** - 200, existing reviews are preserved.
- [x] **Admin can hide reviews** - public average and count drop immediately.
- [x] **Admin can unhide reviews** - public average and count are restored.
- [x] **Dashboard statistics work** - totals, visible/hidden split, platform
      average and top-rated course (with a minimum-review threshold).
- [x] **Invalid input is handled** - 422 with per-field details for bad email,
      rating, name and review length; 404 for an unknown course; 413 for an
      oversized body.
- [x] **Admin endpoints are protected** - 401 without a valid bearer token.

## Frontend quality

- [x] **React is responsive** - grid collapses 3 → 2 → 1 columns; the admin
      course table becomes cards below `md`; mobile navigation works.
- [x] **Loading, empty and error states** on every data screen, with retry.
- [x] **Accessible forms** - labels, `aria-invalid`, `aria-describedby`,
      keyboard-operable star rating, status conveyed by text as well as colour.
- [x] **SPA routing** - deep links such as `/courses/10` and `/admin/reviews`
      render the app (a CloudFront Function on the S3 behavior rewrites
      extension-less paths to `/index.html`; `/api/*` status codes such as
      404 pass through unchanged).
